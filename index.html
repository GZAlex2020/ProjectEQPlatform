部署到 GitHub Pages（两种方式任选其一）

  1. 方式 A · 分支部署（最简单）：把 estimate-platform/ 整个目录作为独立仓库推送到 GitHub；仓库 Settings → Pages → Source 选 Deploy from a branch，分支 main、目录 / (root)。若放进已有仓库，可改名为 docs/ 并把目录选为 /docs。
  2. 方式 B · 自动部署（已附工作流）：目录内已含 .github/workflows/deploy-pages.yml，把 Source 改为 GitHub Actions，之后每次 push 到 main 会自动发布。
  3. 等待 1~2 分钟后访问 https://用户名.github.io/仓库名/；访问 selftest.html 可运行 22 项自动化功能自测。
  4. 已包含 .nojekyll 禁用 Jekyll；全部资源使用相对路径，无需构建、无需 npm、无需后端与数据库。
